# Advanced Specials Manager for Zen Cart

Advanced Specials Manager creates ordinary Zen Cart Specials from reusable product selection rules. A rule can select products by manufacturer, category, base price, stock, model prefix, date added, featured status, and active status.

Current release: **1.0.5**

## Highlights

- Select an entire manufacturer or category.
- Optionally include category descendants.
- Limit products by minimum or maximum base price, stock, date added, or model prefix.
- Include only featured products.
- Include or exclude products priced by attributes.
- Apply a percentage discount, amount discount, or set special price.
- Optionally round calculated discounts to two decimal places.
- Set availability and expiration dates.
- End a rule when either its expiration date arrives or a combined quantity of matching products has sold.
- Preview matches, calculated prices, exclusions, and conflicts before applying a rule.
- Preserve manually created Specials and Specials owned by another rule.
- Remove only Specials created by this plugin when a rule is deleted or uninstalled.

Products priced by attributes continue to use Zen Cart's existing attribute setting, **Apply Discounts Used by Product Special/Sale**. This plugin does not change attribute settings.

## Compatibility

- Zen Cart 2.0.x, 2.1.x, and 2.2.x
- PHP versions supported by the installed Zen Cart release, through PHP 8.5
- MySQL and MariaDB versions supported by Zen Cart

## Use

After installation, open **Catalog > Advanced Specials Manager**. Create a rule, save it, preview the result, and apply it when the matches and calculated prices are correct.

The rule manager writes normal rows to Zen Cart's `specials` table. Storefront templates, checkout choices, price display, feeds, and structured data continue to read normal Zen Cart Specials.

## Important behavior

- Existing manual Specials are never replaced.
- A Special generated by one rule is not claimed by another rule.
- A calculated special price must be greater than zero and lower than the product base price.
- Set price rules use the entered price exactly. Optional rounding does not alter a set price.
- Disabling a rule disables its generated Specials. Applying it again updates the products that still match.
- The preview is advisory. The rule is evaluated again when it is applied.
- Quantity limits count completed order product quantities across all products owned by the rule. Manual stock changes do not affect the counter.

## Uninstall

Plugin Manager uninstall removes the plugin menu, settings, rule tables, and only the Specials tracked as created by this plugin. It does not remove manually created Specials.
